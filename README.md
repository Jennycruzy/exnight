# EXNIGHT

Some price moves are news. Some are arithmetic. EXNIGHT measures which is which on tokenized stocks.

A corporate-action factor for Bitget Reality assets, built by measuring how the 24/5 market reprices ex-dividend events.

The repository currently contains a reproducible public-data adapter, a 63-row study from a saved Bitget distribution notice, an explicit Reality corporate-action builder, and halt-aware normalisation tests. The saved study is not yet a net execution result: eligibility timing, event-time liquidity, and the complete cost model remain unresolved. Weekend trading is limited to selected assets rather than universal 24/7 access.

Every claim in this repository is labelled DOCUMENTED, OBSERVED or ASSUMED.
